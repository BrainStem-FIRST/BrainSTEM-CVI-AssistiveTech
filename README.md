# BrainSTEM-CVI-AssistiveTech
This repository contains Fision360 3D models of the assistive technology used with the BrainSTEM-CVI.app
In addition to the 3D models, code for Arduino MKR Wifi 1010 board for each interface is also provided. 
BrainSTEM CVI is a novel neurovisual learning tool for children with Cortical Visual Impairment.
